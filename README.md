# El Matador

El Matador is a 150 g combat robotics project developed using Autodesk Fusion 360. The chassis has undergone four design iterations so far for component integration, mass optimization, and additive manufacturability.

The current configuration is V4, modified to accommodate a NiMH battery.

##Design constraints:
- Maximum robot mass: 150 g
- Chassis width: approximately 250 mm
- Manufacturing material: ABS
- CAD software: Autodesk Fusion 360

For detailed design changes, see [CHANGELOG.md](CHANGELOG.md).

##Design Version

**V1 — Prototype**  
Rough chassis with electronics integrated, excluding motors and wheels.

**V2 — Weight Reduction**  
Introduced pockets and rib stiffening to reduce weight, but the chassis was still too heavy.

**V3 — LiPo Configuration**  
Reduced chassis length and achieved the target weight.

**V4 — NiMH Configuration**  
Adapted V3 to accommodate NiMH battery.
