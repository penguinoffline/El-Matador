# El Matador

Fusion 360 CAD versions V1–V4.

## Design Evolution

**V1 — Prototype**  
Rough chassis with electronics integrated, excluding motors and wheels.

**V2 — Weight Reduction**  
Introduced pockets and rib stiffening to reduce weight, but the chassis was still too heavy.

**V3 — LiPo Configuration**  
Reduced chassis length and achieved the target weight.

**V4 — NiMH Configuration**  
Adapted V3 to accommodate NiMH battery.
